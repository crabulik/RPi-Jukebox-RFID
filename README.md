# Orest RFID Jukebox

This is a fork of the [Phoniebox](https://github.com/MiczFlor/RPi-Jukebox-RFID) project.

## Purpose

I wanted to build a music box for my son but not invest much time into it. The Phoniebox project was a great starting point, but it had some limitations and areas for improvement. I wanted to experiment with Claude Code to see how easy it would adopt my requirements and ideas.

## What is this?

The project is based on the new **Version 3** of the RPi Jukebox RFID. A complete re-write of the Jukebox. for more detailed information of my modifications please refer to ./documentation/orest/README.md
